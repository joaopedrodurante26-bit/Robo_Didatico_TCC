VERSION - Versao do firmware

REBOOT - Reinicia o ESP32
CLEAR - Limpa o terminal
MOTOR - Entra no menu de motores
SENSOR - Entra no menu de sensores
WIFI - Informacoes do WiFi
FS - Navega no sistema de arquivos
LOG - Atalhos do arquivo de log
DIAG - Executa diagnostico automatico
STOP - Interrompe streams
UI - Mostra/altera interface
